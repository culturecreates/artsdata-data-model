## Reconcile with Wikidata

The Reconcile with Wikidata tool allows registered Artsdata users to load an existing Wikidata entity into Artsdata and assign it an Artsdata ID. Use it when a person, organization, place, or other relevant entity already has a Wikidata record. The tool lets you check for a corresponding entity in Artsdata, link the Wikidata entity to an existing Artsdata ID when a match is found, or mint a new Artsdata ID when needed.

In a simple case, the Wikidata class and Artsdata type will not need to be changed. More advanced cases may require you to manually select or edit the class or type. Detailed written instructions will be added to this page soon.

## Before you begin

Sign in to Artsdata and have the Wikidata URL or QID for the entity you want to reconcile. Before minting a new Artsdata ID, verify that none of the suggested Artsdata records represents the same entity.
